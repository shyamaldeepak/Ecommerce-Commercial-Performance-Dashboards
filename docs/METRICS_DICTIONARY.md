# Commercial Performance Analytics — Metrics Dictionary

This dictionary documents the official commercial metric definitions, underlying SQL transformation logic, grain specifications, and business rules implemented across the Snowflake/DuckDB data marts.

---

## 1. Commercial Revenue Metrics (`mart_revenue`)
**Reporting Grain:** Single Order (`order_id`)

| Metric Name | Business Definition | SQL Calculation Logic | Grain & Allocation Rule |
| :--- | :--- | :--- | :--- |
| **Gross Merchandise Value (GMV)** | Total sales price of goods sold excluding freight and discounts. | `SUM(item_price)` | Item level aggregated to order grain. |
| **Freight Revenue** | Total shipping and handling fees charged to customers. | `SUM(item_freight)` | Item level aggregated to order grain. |
| **Total Commercial Value** | Net commercial transaction value (GMV + Freight). | `gross_merchandise_value + freight_revenue` | Order level. |
| **Total Cash Collected** | Actual payments settled across payment gateways. | `SUM(payment_value)` | Pre-aggregated from `raw_order_payments` to order grain. |
| **Reconciliation Variance** | Parity difference between order cost and collected payments. Must equal $0.00. | `total_commercial_order_value - total_payment_collected` | Verified to equal 0.00 for 100% of orders. |
| **Average Order Value (AOV)** | Average commercial revenue per completed order. | `SUM(total_commercial_order_value) / COUNT(DISTINCT order_id)` | Order grain. |
| **Payment Method Split** | Classification of payment instruments used. | Based on `payment_type` flags (`credit_card`, `voucher`, `boleto`, `debit_card`). | Multi-tender split recognized when `payment_splits_count > 1`. |

## 2. Customer Performance & Cohort Metrics (`mart_customers`)
**Reporting Grain:** Unique Customer Individual (`customer_unique_id`)

| Metric Name | Business Definition | SQL Calculation Logic |
| :--- | :--- | :--- |
| **Customer Lifetime Value (LTV)** | Total cumulative spend by customer across all lifetime orders. | `SUM(order_total_value)` across customer history. |
| **Repeat Customer Flag** | Indicates whether a customer has completed more than 1 order. | `CASE WHEN lifetime_orders_count > 1 THEN 1 ELSE 0 END` |
| **Customer AOV** | Average spend per order for a given customer. | `lifetime_total_spend / lifetime_orders_count` |
| **Recency (Days)** | Elapsed days between customer's most recent order and snapshot date. | `DATE_DIFF('day', last_order_date, '2024-12-31')` |
| **RFM Customer Segment** | Value and behavioral classification based on Recency and Frequency. | - **Champions:** $\ge 3$ orders, Recency $\le 120$ days.<br>- **Loyal:** $\ge 2$ orders, Recency $\le 180$ days.<br>- **New:** 1 order, Recency $\le 90$ days.<br>- **At Risk:** $\ge 2$ orders, Recency $> 180$ days.<br>- **Hibernating:** Recency $> 365$ days. |
| **Customer Tenure** | Lifespan in months from first order to latest order. | `DATE_DIFF('day', first_order_date, last_order_date) / 30.4` |

## 3. Product & Category Performance Metrics (`mart_products`)
**Reporting Grain:** Product SKU (`product_id`)

| Metric Name | Business Definition | SQL Calculation Logic |
| :--- | :--- | :--- |
| **Units Sold** | Total quantity of product items fulfilled. | `COUNT(order_item_id)` |
| **Product Merchandise Revenue** | Cumulative sales revenue generated by the SKU. | `SUM(item_price)` |
| **Average Unit Price** | Average realized sales price per SKU item. | `AVG(item_price)` |
| **Category GMV Rank** | Rank of product by revenue within its specific category. | `DENSE_RANK() OVER (PARTITION BY category ORDER BY revenue DESC)` |
| **Product Satisfaction Score** | Average review score awarded by customers. | `AVG(review_score)` from verified order reviews. |

---

## 4. Seller & Marketplace Operations Metrics (`mart_sellers`)
**Reporting Grain:** Merchant Profile (`seller_id`)

| Metric Name | Business Definition | SQL Calculation Logic |
| :--- | :--- | :--- |
| **Seller GMV** | Total merchandise sales processed by seller. | `SUM(item_price)` for seller's line items. |
| **Orders Fulfilled** | Distinct count of orders handled by seller. | `COUNT(DISTINCT order_id)` |
| **Average Delivery Lead Time** | Average days from purchase to delivery. | `AVG(delivery_lead_days)` |
| **On-Time Delivery Rate (%)** | Percentage of orders delivered on or before estimated date. | `(1 - (delayed_orders / total_items)) * 100` |
| **Seller Rating** | Average customer feedback score for seller's orders. | `AVG(review_score)` |
| **Seller Tier** | Operational and commercial tiering. | - **Elite Merchant:** GMV $\ge \$20k$, Rating $\ge 4.2$, On-Time $\ge 90\%$.<br>- **Established:** GMV $\ge \$5k$, Rating $\ge 3.8$.<br>- **Watchlist:** GMV $< \$1k$ OR Rating $< 3.2$ OR On-Time $< 80\%$. |
